# Three.js Scroll Animation with AETumi

Patterns and examples for building **scroll-driven 3D websites with Three.js**, WebGL, React and Next.js.

AETumi is an AI-native 3D web platform for production-ready interactive websites, 3D components, scenes, prompts and AI coding workflows.

## Scroll experiences covered

- Camera movement tied to scroll progress
- Pinned 3D storytelling sections
- Product reveal sequences
- Parallax depth
- Scene transitions
- Object assembly and exploded views
- Scroll-triggered lighting and material changes
- Narrative landing pages

## Production considerations

- Keep scroll state deterministic
- Avoid excessive main-thread work
- Use requestAnimationFrame responsibly
- Respect reduced-motion preferences
- Lazy load heavy 3D assets
- Design mobile fallbacks intentionally
- Test touch scrolling and resize behavior
